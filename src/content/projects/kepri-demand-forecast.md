## 프로젝트 개요

한국전력공사 전력연구원의 전력 수요 예측 시스템이다. 풀스택 1명과 프론트엔드 3명이 참여했고 R 기반 통계 모델 설계·개발과 서비스 API 구현을 담당했다.

## 전력 수요 예측 관리 사이트

- 사용자가 선택한 변수와 전력 수요량의 상관관계를 분석 및 시각화하는 화면 개발
- 사용자의 선택 변수를 활용하여 미래 전력 수요량을 예측 및 관리하는 기능 구현
- 다양한 데이터 분석 결과를 보고서 형태의 차트 및 그래프(시계열, 회귀 분석 등)로 제공

## 전력 수요 예측 API 및 통계 모델

- Open Source R을 활용한 전력 수요 예측 모델 개발
- 시계열 분석(Time Series Analysis) 및 회귀 분석(Regression Analysis) 기법 적용
- 다중 변수 간 상관관계를 반영한 예측 모델 구성
- 상관관계 분석 API 개발 (변수 간 통계적 유의성 분석)
- 수요량 예측 API 개발 (과거 데이터 기반 향후 전력 소비량 예측)
- R 기반 분석 데이터를 활용한 차트 이미지 변환 API 개발 (보고서 자동 생성)
