## 배경

롯데 GFR이 운영하는 NICE CLAUP 온라인 몰이다. 브랜드 특성상 인스타그램이 주요 마케팅 채널이었기 때문에 인스타그램 피드를 쇼핑몰에 자연스럽게 노출하는 것이 핵심 요구사항이었다. 풀스택 3명으로 진행했고 회원·상품 영역의 API와 화면을 맡았다.

## 상품 화면 개발 및 API 구축

- 상품 목록·상세 정보·필터링 및 검색 기능을 제공하는 API 및 화면 개발
- 다양한 카테고리 및 정렬 옵션 지원

## 인스타그램 브랜드 피드 연계

- Facebook Graph API를 활용해 NICE CLAUP 인스타그램 게시글을 실시간으로 가져와 브랜드 피드 형태로 노출
- 인스타그램 콘텐츠가 곧 상품 홍보 역할을 하도록 쇼핑몰 내 소셜 탭과 연결

## 회원가입 및 로그인

- 일반 회원가입 및 이메일 인증 기능 구현
- 소셜 로그인(Google, Kakao, Naver, Facebook) 4종 연동 — 각 플랫폼별 OAuth2 플로우 처리

## 이벤트 및 관리 기능

- 이벤트 등록·참여·조회 API 및 화면 개발 (쿠폰 발급, 응모 이벤트 등)
- 공지사항·FAQ 카테고리별 검색 기능 개발
