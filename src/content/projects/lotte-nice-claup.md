## 프로젝트 개요

LOTTE GFR의 NICE CLAUP e커머스 플랫폼을 풀스택 3명 규모로 개발했습니다 (기여도 40%).

## 상품 화면 개발 및 API 구축

- 상품 목록, 상세 정보, 필터링 및 검색 기능을 제공하는 API 및 화면 개발
- 다양한 카테고리 및 정렬 옵션을 지원하여 사용자 편의성 개선

## 인스타그램 소셜 기능

- Facebook Graph API를 활용하여 인스타그램 게시글을 연동하고 브랜드 피드 형태로 노출

## 회원가입 및 로그인

- 일반 회원가입 및 이메일 인증 기능 구현
- 소셜 로그인(Google, Kakao, Naver, Facebook) 연동 개발

## 이벤트 및 관리 기능

- 이벤트 등록, 참여, 조회 API 및 화면 개발 (쿠폰 발급, 응모 이벤트 등)
- 공지사항·FAQ 카테고리별 검색 기능 개발
